# The original purge creator retires

The fixed creator keeps its actual command, atomic creation handle and native wait result. Its scope closes only after the same native unit and jobs settle, the original group is empty and the actual creator joins. A saved phase, process number or missing unit cannot replace that producer.

Each scope closure retains its actual wait receipt before closing files. Later retirement checks use that same immutable command and wait result together with the original first-close facts. They do not reopen a retired process descriptor. An unused constructor has a separate cleanup path. A created child which never dispatched a manager call still needs its real native exit and original scope absence before that resource path can finish.

Scope and code-loan files use the shared per-object native retirement owner. A code loan returns to its actual factory only when every original descriptor has known native retirement. Partial loans and partial creators remain reachable on errors. A second Close or ErrClosed cannot establish native retirement.

The native creator adopts its actual peer and connection before a late failure. Its original startup line attaches the same resource pool before the first read. Cancellation interrupts I/O with a deadline, then joins the actual child and native scope before closing that line, the original process handle and code loans.

Semantic diagnostics stay available after known native retirement. They remain errors in the original operation outcome. Actual native retirement alone controls physical progress and the scope's charge. Unknown state keeps the original owner. No resource retirement record grants a session stop, a current-copy source, a native unit or filesystem deletion.

The regression fixture now keeps an untracked already-closed adoption file unknown on every retry. It cannot turn a second Go close result into a completed constructor. Compiler and native execution remain separate qualification steps.
