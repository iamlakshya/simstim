# Resume preparation publication

A cold resume preparation uses the existing placement publication ledger. Its closed kind is `resume_prepare`. Installer payloads cannot start this operation. The original operation token and record stay under the same placement control gate.

The record accounts for active work. It does not prove native absence, admission, a boot, or permission to fetch keys. Those requirements still come from the original native cold source and its own retained session operation.

The memory reservation remains until the actual new native cap and membership take over, or the original physical cancellation finishes. Starting metadata and an acknowledgement do not settle it.
