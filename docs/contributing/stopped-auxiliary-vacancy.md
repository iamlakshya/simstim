# An auxiliary read after a physical stop

A current-boot read needs the original whole-stop owner and the same session
operation. The private adapter checks the original exited process, empty native
cgroup, both absent units and both absent cgroups. It duplicates the still-locked
holder description and checks a separate root descriptor. It retains a fresh
authenticated manager connection for the auxiliary lifetime.

This vacancy enters the existing artifact capture, memory reservation and new
native activation. The private loan still carries the original operation,
holder and saved disk descriptors. Closing the auxiliary reader waits for its
whole native lifetime before clearing its reservation. No agent, secret or
network service starts. A saved status, copied manifest or empty socket cannot
construct this source.

The initial artifact consumer supports the recorded microvm source. Other
walls and ordinary unwalled holders still need their own physical producers.
Purge also needs its original drain owner and a complete read of unsaved work;
this adapter alone proves neither permission nor clean work.
