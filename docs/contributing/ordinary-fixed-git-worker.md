# Fixed ordinary Git worker

The active ordinary inspection starts the current helper with one literal purpose: `git-op purge.inspect`. The outside owner retains the same operation, active preparation and original-root permit. It captures the helper's process descriptor atomically at creation and owns its real `Cmd.Wait`.

The original outside owner creates a temporary private Unix endpoint beneath a retained runtime-root descriptor. The actual new child connects to it. Before sending private root loans, the outside side checks the current SCM sender, socket peer, helper code and host namespaces against that exact original creation. It also checks the original literal arguments and endpoint generation. A different same-user process receives no root loans and is never signalled.

The child receives only the fixed read plan and three original directory loans. It cannot select another command, create a stopped source or authorise cleanup. Each Git command gets explicit worktree, administrative and common-root descriptors. Inherited Git environment selectors are removed. The command uses the shared safe options and the same version gate as existing host Git operations.

Each actual Git creation has its own original process descriptor, `Wait` and output readers. Cancellation signals that original creation and joins its readers. It never signals a named process group. Output and stderr have fixed bounds. A pipe held by an escaped descendant produces an unknown inspection at the deadline. The bounded N5 claim does not say that escaped filters were stopped.

The child joins its commands before sending counts. It waits for the original outside reader to acknowledge the exact result continuation, then exits. The outside side joins that original helper before it checks the active permit again. Its opaque result checks those native joins and the same current operation, preparation, mapping and roots before returning counts. Closing it retains root loans until that actual helper and reader have joined.

This worker currently supports the bounded ordinary producer. Managed worker creation and whole-unit settlement need their distinct native source. Public purge remains on its conservative path until temporary attempt custody, managed and walled preparations and all-session initial and final checks are joined. The command and filesystem tests are source tests; native helper and complete purge acceptance remain unproved.
