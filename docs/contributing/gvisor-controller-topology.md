# Original controller topology

The actual start producer now freezes its captured mount objects into a sealed public topology before constructing the native command. The original host factory checks that same capsule against its original session and mount plan. The capsule retains only native file or directory objects, source indices, fixed guest targets and the fixed guest-init or smoke role. It carries no host path, private operation, guest link, agent command, environment or raw OCI.

Approved kept state remains an opaque original session object. Restore and capture generations keep distinct fixed targets and access modes. The public projection duplicates those same native objects and the sealed descriptor for the mapped controller writer. Closing the original capsule does not adopt its public projection as a new owner.

The sandbox retains its original capsule through actual command exit. Early construction failures and positive native cleanup close it. Uncertain physical exit retains it with the original runtime. The fixed native vector admits at most 1000 source objects.

The mapped controller writer consumes this same public projection. The outside
owner joins its actual native creation, code, namespace, filesystem and
aggregate checks before the original operation can lend the guest stream.
[The production route](gvisor-controller-production.md) describes those
calls. Source implementation does not establish native availability.
