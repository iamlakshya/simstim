# Ordinary sessions and copied purge code

The protected removal process keeps its actual copied executable separate from the original helper image. Its independently installed host domain supplies the copied image. A request, path or public descriptor cannot supply it.

An ordinary holder keeps its original locked file description, native main creation and session root. The removal process checks that holder against its retained original helper image. The holder checks the outside operator's native credentials, pinned process, cgroup placement and namespace observations before lending its own native objects. Exact public code bytes restrict this closed request path. They do not attest the peer's current executable or grant an operation. The holder's existing access check still applies.

The fixed Git reader starts through the actual retained executable descriptor. Its raw entry protects the process before normal helper initialisation. It checks inherited readable code against its own current kernel mapping and checks its original parent's live pidfd and current socket sender. The creator retains the fixed command, atomic child pidfd, original wait result and private endpoint before lending inspection roots. Endpoint cleanup finishes before those objects are released. Cancellation joins the same readers and original child.

Generic helper handshakes still require the same executable image. Neither path accepts a saved source, absence claim, foreign operation or another session's native objects. Unknown placement, changed credentials and replaced roots remain refusals. Force does not establish ownership.
