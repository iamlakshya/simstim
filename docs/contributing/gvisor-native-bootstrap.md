# The fixed native bootstrap

This source joins the native identity and descriptor stages. It does not establish working or accepted native gVisor. The signed runtime's topology and final filesystem boundary remain separate work.

The original host retains the actual C creator and its creation pidfd. The fixed C role creates A as PID 1, clears groups before its first deny, maps only the login UID and GID, and checks real, effective and saved IDs. It verifies empty groups and actual non-dumpability before making a new control socket. The premap control never receives later private rights.

The fixed helper entry asserts non-dumpability again after exec. It consumes only the versioned public slot prelude first. Both control roles move above the original target range and their old slots immediately become nulls. Go can then allocate its poller without occupying future target slots. The original command derives the count from its actual captured layout; a supplied count is no permission. Partial, duplicate or changed roles refuse before release.

The same native helper, task birth, parent chain, proc objects and fresh socket bind the later transfer. A builds its safe root, becomes capability-free and installs its fixed syscall policy. On kernels with IPC and signal scopes, A installs one common scope before creating the child. Only that actual success issues the private, thread-bound proof for A's later filesystem-only layer. Generic profiles and the child's own scopes keep their existing rules.

The child self-maps exactly one identity, checks empty groups and actual non-dumpability, and mounts fresh proc for its own PID namespace. Global controls are read-only. Native task, namespace, birth and socket observations prove its ancestry. PID 0 alone is never permission. All proof and original raw wrappers close before final release. The same creation child is signalled and joined on failure; uncertain physical exit retains its owner.

The current filesystem layers block mount, pivot and unmount after enforcement. The selected signed runtime's normal gofer setup requires those operations. The next versioned phase must complete trusted immutable topology before each role's final filesystem boundary, while withholding guest links, secrets, original operations and agent payload. No generic bypass or test-only flag is permitted. Physical probe caching must also bind the same captured C code object, alongside the helper, complete runtime, boot, kernel and native domain.

Host-login compromise is outside the stated threat model. Non-dumpability does not stop a parent-user-namespace owner with the relevant capability. Tests must identify each in-scope attacker by its actual native UID, capabilities and namespaces, including every exec reset window. Source and compilation prove none of these native behaviours.
