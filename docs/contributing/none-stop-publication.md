# Publishing an unwalled stop

The public stop command selects the original unwalled supervisor through its
recorded execution path. That selection supplies no native stop authority.
The original N5 producer must join its init, main process, terminal, streams
and incoming operation loan, then prove exit of the same captured supervisor.

A separate publisher consumes only `StoppedNoneSessionV1` on the same original
operation. It checks primary and member roots and the held manifest inode
before writing the stopped record. It does not use a VM, whole-unit or
ordinary-holder stopped checker.

The shared projection handles data only. It preserves any original
`NoneCleanupV1` field from the supervisor's final save. A stopped row, stop
request or failed wait cannot manufacture that field or a later resume source.
