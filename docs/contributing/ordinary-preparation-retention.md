# Ordinary preparation retention

A failed active capture can return both its same real unready owner and an error. The preparation factory adopts that object before handling the error. It grants no stopped or cleanup authority. Closing an unused capture closes only its actual borrowed objects; the original producer records the physical quiesce-send boundary before any pause can be requested.

After a quiesce send, the preparation must join the holder's original restoration acknowledgement. Repeating Restore rechecks that native completion, the same original operation and root, the actual live producer and the unused destructive-join object. A local restored field cannot release those obligations.

Legacy stopped-call signatures cannot return an unready stopped subject. A failed unused native capture therefore retains its same owning stack until its actual close succeeds. No status, path or retry journal reconstructs that owner.

These changes preserve the existing ordinary producer and its bounded N5 claim. Complete native failure and cancellation acceptance still needs Root's approved execution.
