# Original jail lifetime checks

The native live check accepts only the same actual started command and its retained kernel creation handles. A normal Wait may already be active; an unstarted, failed, uncertain, reaped or closed owner refuses. The userspace-kernel path also retains its original C creator, actual A creation handle and verified mapped-code bootstrap.

This check supplies no warm, stop, boot, capacity or recovered-process permission. A genuine warm producer must still retain the same actual Start connection, guest/runtime identity and original operation and native source. A reopened sandbox, path, saved row, PID or response cannot manufacture that source. Native child and connection checks remain separate from this original command lifetime observation.
