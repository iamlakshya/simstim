# Optional persistent manager stop ownership

A retained stop first checks its actual original committed supervisor. An
already registered persistent owner retains its own original native objects.
That registration comes only from the concrete persistent runtime producer,
after its original kernel and native service checks. No row, boolean, callback
or descriptor setter can register a source.

Missing registration supplies no custody receipt. The helper must instead
prove its actual current main belongs to the canonical original transient
service, with native `Transient=true`, no descriptor store and no stored
objects. Its ordinary stop and absence checks then remain unchanged.
A persistent, changed or unknown service without its bound owner is refused.

The interface is sealed to the host package's concrete native producers.
Its presence does not activate persistent runtime creation or cold resume.
