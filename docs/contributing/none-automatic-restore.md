# Automatic unwalled restore

The automatic None continuation has its own original owner. The actual host
restore controller supplies its retained global restore gate and the same
session operation. The native gate file, its state-metadata publisher and its
lifetime must still match. A copied automatic selection cannot issue a source.

This origin accepts a genuine prior kernel boot. It reuses only the distinct
None holder, metadata and actual first-creator consumers. It never adopts a VM
artefact, declared VM memory quantum or whole-unit stopped source.

The public restore controller selects this origin before the walled automatic
selection. Idle unwalled sessions use a separate checked data publication and
keep their prior boot identity. Working sessions bind the actual None source
before the real native launcher and original operation-loan handoff run.

The same-boot managed None origin remains separate. It must consume the real
manager kernel custody class and cannot fall back to managerless observations.
